# eWallet API Ecosystem 🚀

A professional Backend solution for digital wallet management built with **.NET 8/9** following **Clean Architecture** principles.

## 🛠 Tech Stack
- **Framework:** ASP.NET Core Web API
- **Database:** SQL Server (EF Core)
- **Security:** JWT Authentication & ASP.NET Identity
- **Patterns:** Repository Pattern, Unit of Work, and Specification Pattern.
- **Mapping:** AutoMapper

## ✨ Key Features
- **Wallet Management:** Automatic wallet creation for new users.
- **Transactions:** Secure deposit and withdrawal operations with atomic updates.
- **Filtering:** Dynamic transaction filtering using the Specification pattern.
- **Security:** Fully secured endpoints with Role-Based Access Control.
- **Documentation:** Interactive API documentation via Swagger UI.

## 🚀 Live Demo
- **API Endpoint:** [http://ewallet-system.runasp.net/swagger/index.html]

## 🏗 How to Run Locally
1. Clone the repository: `git clone [eWallet-API-Ecosystem]`
2. Update `appsettings.json` with your Connection String.
3. Run `Update-Database` in Package Manager Console.
4. Press `F5` to start.
